# 스마트폰 영상 제작 실습 교안집

> ELEMENTARY MEDIA CLASS　/　2 SESSIONS　/　초등학교 3~6학년 (스마트폰 기본 조작 가능)

캡컷(CapCut)으로 만드는 나만의 첫 영상. 찍고, 자르고, 자막과 음악을 넣어 30초 영상을 완성합니다.

## 과정 개요

| 항목 | 내용 |
|---|---|
| 과정명 | 스마트폰 영상 제작 실습 교안집 |
| 대상 | 초등학교 3~6학년 (스마트폰 기본 조작 가능) |
| 구성 | 2개 강의 · 총 100분 |
| 강사 | 미디어 교육 강사 |

## 과정 목표

- 좋은 영상 촬영의 3가지 규칙을 지켜 짧은 장면을 찍을 수 있다
- 캡컷에서 영상을 자르고 순서를 바꾸는 기본 편집을 할 수 있다
- 자막·음악·전환 효과를 넣어 30초 영상을 완성하고 저장할 수 있다
- 친구를 찍을 때 허락을 구하는 등 영상 예절을 지킨다

## 준비물

- 캡컷이 설치된 스마트폰 또는 태블릿 (2인 1대도 가능)
- 충전기, 저장 공간 1GB 이상
- 캡컷 이용 연령 기준에 맞춘 학교 기기 또는 보호자 동의
- 촬영할 소품 (필통, 지우개, 좋아하는 물건 등)

#### [05:00–13:00] 개념 — 촬영 3규칙과 장면 3종류 설명

**강사 멘트**

> 좋은 영상에는 비밀 규칙이 세 개 있어요. 첫째, 스마트폰을 옆으로 눕혀 가로로! 둘째, 두 손으로 꼭 잡고 흔들리지 않게! 셋째, 밝은 곳에서 찍기!
> 그리고 장면은 멀리, 가까이, 아주 가까이 세 가지로 찍으면 훨씬 재미있어져요.

- **학습자 활동**: 스마트폰 가로로 들고 두 손 자세 따라 하기
- **진행 팁**: '가로! 두 손! 밝게!' 구호를 함께 외치게 하면 잘 기억합니다.

**강사 멘트**

> 이름표, 집 주소, 학교 이름이 영상에 나오지 않게 조심해요.

- **학습자 활동**: 짝에게 '찍어도 돼?' 묻고 대답하는 연습
- **진행 팁**: 얼굴 대신 손이나 물건 위주로 찍도록 유도하면 예절 문제가 줄어듭니다.

**강사 멘트**

> 멀리서 한 번, 가까이서 한 번, 아주 가까이서 한 번! 한 장면은 3초에서 5초면 충분해요.

- **학습자 활동**: 소품 하나를 정해 멀리·가까이·아주 가까이 3컷 촬영

> 필요 없는 부분은 흰 선을 옮기고 '분할'을 눌러 자른 다음 '삭제'해요. 클립을 꾹 누르면 순서도 바꿀 수 있어요.

- **학습자 활동**: 새 프로젝트 → 클립 3개 추가 → 분할·삭제 → 순서 바꾸기
- **진행 팁**: 화면 미러링으로 손동작을 크게 보여 줍니다. 앞뒤 흔들린 1초를 자르는 것부터 시키면 쉽게 성공합니다.

### 실습 프롬프트

#### 미션 1 · 내 물건 소개 3컷

```
① 좋아하는 물건을 하나 골라요.
② 멀리서 찍기 — 책상 위 물건이 다 보이게 (3~5초)
③ 가까이 찍기 — 물건 하나가 화면에 꽉 차게 (3~5초)
④ 아주 가까이 찍기 — 무늬나 글씨가 보이게 (3~5초)
⑤ 가로·두 손·밝게, 3규칙 지켰는지 확인!
```

#### 미션 2 · 자르고 이어 붙이기

```
① 캡컷 → 새 프로젝트 → 영상 3개 선택 → 추가
② 영상 맨 앞 흔들린 부분에 흰 선 놓기 → 분할 → 삭제
③ 영상 맨 끝 부분도 똑같이 잘라 내기
④ 클립을 꾹 눌러 '멀리 → 가까이 → 아주 가까이' 순서 맞추기
⑤ ▶ 재생해서 처음부터 끝까지 확인!
```

#### 빨리 끝낸 친구 도전 미션

```
속도 바꾸기: 클립을 누르고 '속도' → 아주 가까이 장면을 0.5배 느리게 만들어 보세요.
```

집에서 우리 집 반려동물이나 화분을 멀리·가까이·아주 가까이 3컷으로 찍어 오기 (가족 얼굴은 허락받고!)

### 강사용 노트

기기마다 캡컷 화면이 조금 다를 수 있으니 수업 전에 같은 버전으로 업데이트해 두세요. 2인 1대로 진행하면 촬영자와 출연자 역할을 꼭 바꿔 주세요. 캡컷은 이용 연령 기준이 있으니 학교 기기를 쓰거나 보호자 동의를 미리 받아 두세요.

- 캡컷 내장 음악을 넣고 볼륨을 조절할 수 있다
- 전환 효과를 넣고 영상을 내보내기로 저장할 수 있다

### 준비물

- 1차시 캡컷 프로젝트
- 자막 문구 예시 (실습 미션 페이지)

- **학습자 활동**: 클립 사이 전환 효과 2개, 스티커 1개
- **진행 팁**: 효과를 너무 많이 넣으면 정신없어 보인다는 점을 짚어 줍니다.

> 저장될 때까지 화면을 끄지 말고 기다려요!

- **학습자 활동**: 내보내기 → 사진 앱에서 영상 확인
- **진행 팁**: 내보내기 중 앱을 나가면 실패하니 기다리게 합니다. 저장 공간 부족 시 해상도를 720p로 낮춥니다.

- **진행 팁**: 화면 미러링으로 상영하고, 상영 전 출연한 친구에게 다시 한번 동의를 구합니다.

### 실습 프롬프트

#### 자막 문구 예시

```
내 보물 필통을 소개합니다!
멀리서 보면 이런 모습
가까이 보면 반짝반짝
여기가 제일 좋아요!
끝까지 봐 줘서 고마워요
```

#### 미션 3 · 자막 넣기

```
① 아래 메뉴 '텍스트' → '텍스트 추가'
② 첫 장면에 제목 쓰기
③ 두 손가락으로 벌려 글자 크게, '스타일'에서 색 바꾸기
④ 다른 장면에도 설명 자막 2개 더 넣기
⑤ 자막은 한 줄 10글자 이내로 짧게!
```

#### 미션 4·5 · 음악과 효과

```
① '오디오' → '사운드'에서 음악 고르기 → '+' 눌러 넣기
② 음악 클립 누르고 '볼륨'을 50 정도로 낮추기
③ 음악이 영상보다 길면 끝에서 분할 → 삭제
④ 클립 사이 하얀 네모 눌러 전환 효과 넣기 (2개)
⑤ 시간이 남으면 '스티커'로 꾸미기
```

#### 빨리 끝낸 친구 도전 미션

```
자막 애니메이션: 자막을 누르고 '애니메이션' → '시작'에서 글자가 톡 튀어나오게 만들어 보세요.
```

### 확인 및 평가

- 자막을 3개 이상 넣었는가
- 캡컷 내장 음악을 사용하고 볼륨을 조절했는가
- 내보내기로 영상을 저장했는가
